# 14 — PROGRESS.md template

Utwórz `docs/PROGRESS.md` w istniejącym repo i utrzymuj krótki aktualny stan (nie kopiuj całych logów konsoli).

```
# POGRANICZE — status
Data:
Gałąź / commit:
Etap (M0-M6):
Co działa teraz (dowód):
Co celowo pozostaje placeholderem:
Zmienione komponenty:
Testy: [komponent, check, PASS/FAIL/NOT RUN, uwagi]
SpriteCook: [plugin/autoryzacja/kredyty/hero asset/status]
Blokery — tylko wymagające działania człowieka:
Następne 1–3 działania:
```

Prawdziwy wynik działania aplikacji jest ważniejszy niż liczba plików utworzonych przez agenta.
